۱

سفارش بساز

مبلغ و عنوان را می‌فرستی. سیستم یک مبلغ یکتا با اختلاف چند ریال برمی‌گرداند.

۲

مشتری را بفرست

لینک پرداخت را باز می‌کنی. مشتری کارت‌به‌کارت می‌کند و مبلغ دقیق را واریز می‌کند.

۳

واریز تطبیق می‌خورد

پیامک بانک خوانده می‌شود و مبلغ یکتا به سفارش درست وصل می‌شود.

۴

وضعیت را بگیر

با یک درخواست GET ببین paid شده یا نه. تمام.

چرا این روش

بدون واسطه، بدون کارمزد درگاه

پول مستقیم به حساب خودت می‌رود. نه تسویه‌ای در کار است، نه کارمزدی.

تطبیق خودکار

مبلغ یکتا تضمین می‌کند واریز به سفارش درست وصل شود، حتی وقتی چند سفارش همزمان باز است.

امضای HMAC

هر درخواست با HMAC-SHA256 امضا می‌شود. پنجرهٔ زمانی ۳۰۰ ثانیه و nonce یکتا جلوی replay را می‌گیرد.

بدون webhook

اگر سرور شما لحظه‌ای خاموش باشد، هیچ پرداختی گم نمی‌شود. استعلام همیشه وضعیت واقعی را می‌دهد.

idempotency

با external_ref هر بار همان سفارش برمی‌گردد. دوبار کلیک کردن سفارش دوم نمی‌سازد.

بدون وابستگی

PHP فقط cURL می‌خواهد. Node از fetch بومی استفاده می‌کند. Python فقط کتابخانهٔ استاندارد.

شفاف

وضعیت‌ها صریح‌اند: pending، paid، expired، canceled. هیچ حدس و گمانی نیست.

شروع سریع

سه خط تا اولین پرداخت

کلید API را از پنل پرداختیار بگیر: تنظیمات → کلیدهای API. سپس:

// نصب: فایل Connect.php را کنار پروژه بگذارید
require 'sdk/php/Connect.php';

$pay = new Pardakhtyar\Connect(
    'https://pay.lenvato.ir',
    'ak_...',   // کلید API
    '...'       // کلید مخفی — در متغیر محیطی
);

$order = $pay->createOrder([
    'amount'       => 250000,          // تومان
    'title'        => 'اشتراک ماهانه',
    'external_ref' => 'INV-1001',      // جلوگیری از تکرار
]);

header('Location: ' . $order['pay_url']);
// نصب: فایل connect.js را کپی کنید — بدون npm install
const { Connect } = require('./sdk/node/connect');

const pay = new Connect({
  baseUrl: 'https://pay.lenvato.ir',
  keyId: process.env.PAY_KEY_ID,
  secret: process.env.PAY_SECRET,
});

const order = await pay.createOrder({
  amount: 250000,
  title: 'اشتراک ماهانه',
  external_ref: 'INV-1001',
});

res.redirect(order.pay_url);
# نصب: فایل pardakhtyar_connect.py را کپی کنید
from pardakhtyar_connect import Connect

pay = Connect(
    base_url='https://pay.lenvato.ir',
    key_id=os.environ['PAY_KEY_ID'],
    secret=os.environ['PAY_SECRET'],
)

order = pay.create_order(
    amount=250_000,
    title='اشتراک ماهانه',
    external_ref='INV-1001',
)

print(order['pay_url'])
مهم: مشتری باید مبلغ دقیق را واریز کند، نه مبلغ گرد. اختلاف چند ریالی همان چیزی است که واریز را به سفارش درست وصل می‌کند. اگر مبلغ را گرد کند، تطبیق انجام نمی‌شود و تراکنش در صف «بررسی دستی» می‌ماند.
مرجع API

پنج اندپوینت، همین

همهٔ درخواست‌ها JSON هستند. مسیر پایه: https://pay.lenvato.ir

متدمسیرکاراحراز هویت
POST /api/v1/orders ساخت سفارش با مبلغ یکتا بله
GET /api/v1/orders/{code} جزئیات سفارش بله
GET /api/v1/status/{ref} استعلام وضعیت — کد سفارش یا external_ref بله
POST /api/v1/links ساخت لینک پرداخت بدون سفارش بله
GET /api/v1/public/status/{token} وضعیت عمومی لینک — برای صفحهٔ مشتری خیر

هدرهای احراز هویت

هدرمقدار
X-Api-Keyشناسهٔ کلید، مثل ak_ac7de27e0d74
X-Api-SignatureHMAC-SHA256(timestamp + "\n" + nonce + "\n" + raw_body, secret)
X-Api-Timestampزمان یونیکس — حداکثر ۳۰۰ ثانیه اختلاف
X-Api-Nonceرشتهٔ تصادفی یکتا در هر درخواست

سؤالات متداول

چیزهایی که معمولاً می‌پرسند

اگر کاربر صفحه را ببندد؟

مشکلی نیست. تأیید به بازگشت کاربر وابسته نیست — سرور شما هر وقت بخواهد استعلام می‌گیرد.

اگر مبلغ را گرد کند؟

سفارش تأیید نمی‌شود. تراکنش در صف «بررسی دستی» می‌ماند تا خودتان وصلش کنید.

چند سفارش همزمان؟

هر تعداد. مبلغ یکتا برای هر سفارش جدا محاسبه می‌شود، پس تطبیق اشتباه نمی‌شود.

کلید مخفی کجا نگه دارم؟

فقط در متغیر محیطی. هرگز در کد، در مخزن گیت، یا در جاوااسکریپت سمت مرورگر.

آیا webhook دارد؟

نه. طراحی عمداً polling است تا اگر سرور شما قطع شد، پرداختی گم نشود.

چه بانک‌هایی؟

هر بانکی که پیامک واریز بفرستد. تطبیق بر اساس متن پیامک و مبلغ انجام می‌شود.

آماده‌اید وصل کنید؟

کلید API را از پنل بگیرید، کتابخانه را کپی کنید، سه خط کد اضافه کنید.
